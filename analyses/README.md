# Analysis workflow

The active analysis notebooks are numbered 01–11. Notebook numbers describe workflow organisation; supplementary figure and table numbers follow the manuscript and do not need to match notebook numbers.

## Execution order and outputs

| Step | Notebook | Main outputs |
|------|----------|--------------|
| 01 | `01-tse-construction.qmd` | Discovery (2,488 vOTUs) and primary (962 vOTUs) TSE objects |
| 02 | `02-fig2-viral diversity.qmd` | Figure 2; Table S1 |
| 03 | `03-fig3-abundant-rare-viral.qmd` | Figure 3: abundant and rare vOTUs |
| 04 | `04-fig4-heatmap.qmd` | Figure 4: candidate AMG/pathway heatmaps; input table for step 09 |
| 05 | `05-figs1-host-composition.qmd` | Figure S1: predicted host composition |

| 08 | `08-figs4-rare-patterns.qmd` | Figure S4: rare vOTU patterns |

## Running the notebooks

From the repository root:

```bash
quarto render analyses/01-tse-construction.qmd
quarto render "analyses/02-fig2-viral diversity.qmd"
quarto render analyses/03-fig3-abundant-rare-viral.qmd
quarto render analyses/04-fig4-heatmap.qmd
quarto render analyses/05-figs1-host-composition.qmd
quarto render analyses/06-figs2-lifestyle.qmd
quarto render analyses/07-figs3-abundant-patterns.qmd
quarto render analyses/08-figs4-rare-patterns.qmd
quarto render analyses/09-figs5-amg-DA.qmd
quarto render analyses/10-figs7-folA-candidate.qmd
quarto render analyses/11-figs8-public-reference.qmd
```

Step 01 reads the tracked SQLite/TSV in `data/00-raw/d00-resource/`. Subsequent TSE-based analyses read its generated outputs. Step 04 queries KEGG online; step 09 reads `data/04-fig4-heatmap/deduplicated_pathway_table.xlsx`. Do not interpret a render with failed KEGG queries as successful annotation.

Step 10 requires these tracked archived inputs:

```text
data/16-amg-targeted-validation/
  tables/genomic_context_orfs.csv
  tables/superposition_verification.csv
  structures/render_d_FCH3CGLCCXYL4FAA_NODE_14_9_esmfold_on_1RX2.png
```

The structure PNG is an input layer, not a disposable output preview. Step 10 does not rerun ESMFold or TM-align.

Step 11 requires both tracked inputs:

```text
data/00-raw/d11-figs8-public-reference/
  published_reference_coverage.csv
  public_reference_alignments_primary962.csv
```

They contain 36 published coverage records and nine primary-catalogue reference-match records, respectively. Step 11 checks these inputs, draws S8 and exports Table S2; it does not rerun read mapping or nucleotide alignment.

## Table S3 and report synchronisation

Step 06 Task 7 writes the following to `data/06-figs2-lifestyle/quality_sensitivity/`:

- `Table_S3a_quality_counts.csv`: quality-group counts.
- `Table_S3b_quality_sample_fractions.csv`: quality-by-sample summaries.
- `Table_S3_comparison.csv`: four-sample comparison.
- `Table_S3_source_vOTU_TPM.csv`: 962 source vOTUs and their TPM values.

These CSVs are generated by the code and are tracked for numerical inspection. The separately formatted submission Excel workbook uses these results but is not exported by step 06.

When updating a notebook, also update its tracked Markdown report and referenced preview images. Use `quarto render <notebook.qmd> --to gfm` for GitHub reports. Temporary TIFFs and HTML libraries are not required in Git. Figure 2b intentionally has no fixed random seed; rerun rarefaction curves may differ.
